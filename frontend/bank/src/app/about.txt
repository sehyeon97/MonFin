Thi app folder contains all the different pages.
For example, bank account page, transaction page, card management page, etc.
It can be thought of as one giant component.
Contains UI unique to a route.
Folders within app folder are routes.
If the inner folder is named auth, the route is /auth

NextJS is file-based routing unlike React.
Therefore, each folder here will have a page.tsx folder.
In the root page.tsx, include these as something like:
<Link href="/accounts">
    View Accounts
</Link>
from import Link from "next/link"
